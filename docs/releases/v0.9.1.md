# HomeTiles v0.9.1

v0.9.1 moves the Material Design icons into a file on the panel, which frees room in the firmware, and applies the entity rule to energy data.

## Highlights

- More room in the firmware: all 7447 Material Design icons now live in a file on the panel. The M5Stack Tab5 image shrinks from 6.8 MB to 4.8 MB. The 399 most used icons stay built in, including Home Assistant's default icons.
- Energy tile: the picker finds the sources of the Home Assistant Energy dashboard through the Bridge. A tile shows its source's icon by itself.
- Energy data only as released: without a Web Admin password a panel gets only the categories enabled under Energy Dashboard in the Bridge options, like every other entity.
- The Web Admin follows a Web Admin password that is set or removed on the panel.
- No more scroll bars around the preview at 125 % display scaling.

## Update Notes

Update to **[HomeTiles Bridge v0.9.1](https://github.com/GalusPeres/HomeTiles-Bridge/releases/tag/v0.9.1)** first. On a panel without a Web Admin password, enable the Energy Dashboard categories you use in the Bridge options; otherwise its Energy tiles stay empty.

After the update each panel downloads its icon file once from this release (1.3 to 2 MB) and restarts once. It needs internet access to GitHub for this. Without it, the panel shows the built-in icons and a placeholder for the others, and tries again on the next restarts.

Use the regular `.bin` for OTA or the browser installer's **Update** mode. Use `_factory.bin` only for a first installation or an intentional reset. Select the exact board and revision.

Going back to v0.9.0 works. The icon file stays on the panel and is used again after the next update.

## Hardware Confirmed

The maintainer tested this release's code on M5Stack Tab5, Guition JC8012P4A1 V2 and Guition ESP32-4848S040 (S3). The tests covered the icon download, icons under camera and screensaver load, and the energy picker with and without a Web Admin password.
